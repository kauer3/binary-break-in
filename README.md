<p>
Binary Break-In is a two-player asymmetric co-op game built in Unity. One player steps into a VR action role as an armed infiltrator, while the other plays as a hacker on PC. Work together to breach a procedurally generated map, retrieve a secure briefcase, and escape while combating guards. The VR player fights off enemies and uses a device to grant the hacker access to in-world terminals. The hacker, with a top-down third-person view, provides directions and hacks terminals and doors to help the infiltrator progress through the map. This game was developed as my Game Development 2 project for my Bachelor of Information Technology.
</p>
